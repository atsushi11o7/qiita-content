# 1. Tailwind のトランジションユーティリティ

最もシンプルなアニメーションは Tailwind のトランジション系クラスだけで実現できます。

## ホバーエフェクト

```tsx
<div className="
  transition-all duration-300
  hover:-translate-y-1
  hover:shadow-lg
">
  カード
</div>
```

実際に使ったカードコンポーネントの例：

```tsx
// ArticleCard.tsx
<Link
  href={href}
  className="
    group block bg-card border border-border rounded-xl
    transition-all duration-300
    hover:-translate-y-1 hover:shadow-lg
  "
>
  {/* サムネイル画像のズームアニメーション */}
  <img
    className="w-full h-full object-cover
      group-hover:scale-105 transition-transform duration-500"
  />
</Link>
```

`group` / `group-hover:` の組み合わせで、親要素のホバー時に子要素をアニメーションさせられます。

## よく使うトランジションクラス

| クラス | 効果 |
|---|---|
| `transition-all` | すべてのプロパティを対象 |
| `transition-transform` | transform のみ（パフォーマンス優先） |
| `duration-300` | 300ms |
| `ease-out` | 減速して終わる |
| `hover:-translate-y-1` | 上に 4px 移動 |
| `hover:scale-105` | 5% 拡大 |
| `hover:shadow-lg` | 影を追加 |

# 2. CSS `@keyframes` で繰り返しアニメーション

ホバーではなくページロード時や無限ループのアニメーションには `@keyframes` を使います。

Tailwind CSS v4 では `globals.css` に直接書き、クラス名で管理します。

## フェードインアップ

```css
/* globals.css */
@keyframes fade-in-up {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.anim-fade-in {
  animation: fade-in-up 0.8s ease-out both;
}
.anim-fade-in-delay-1 {
  animation: fade-in-up 0.8s ease-out 0.15s both;
}
.anim-fade-in-delay-2 {
  animation: fade-in-up 0.8s ease-out 0.3s both;
}
```

```tsx
// Hero セクションでの使用例
<h1 className="anim-fade-in">タイトル</h1>
<p className="anim-fade-in-delay-1">サブタイトル</p>
<div className="anim-fade-in-delay-2">バッジ一覧</div>
```

`animation-fill-mode: both`（`both` キーワード）を指定することで、アニメーション開始前は `from` の状態を維持します。これを忘れると、ページ表示の一瞬だけ要素が見えてしまいます。

## 浮遊アニメーション（無限ループ）
要素がゆっくり上下・左右に動き続けるアニメーション。
ページ背景の装飾として採用。

```css
@keyframes float {
  0%, 100% { transform: translateY(0); }
  50%       { transform: translateY(-8px); }
}

.anim-float {
  animation: float 6s ease-in-out infinite;
}
```

## グラデーションアニメーション
文字の色をグラデーションにするために採用。

```css
@keyframes gradient-shift {
  0%   { background-position: 0% 50%; }
  50%  { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}

.anim-gradient-text {
  background: linear-gradient(135deg, #171717 0%, #6366f1 50%, #171717 100%);
  background-size: 200% auto;
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
  background-clip: text;
  animation: gradient-shift 6s ease-in-out infinite;
}
```

```tsx
<h1 className="anim-gradient-text">
  A space to share daily learnings
</h1>
```

# 3. React の `useState` でアニメーション制御

表示・非表示の切り替えなど、インタラクションに応じたアニメーションは `useState` と CSS を組み合わせます。

## フェードイン・アウト

```tsx
'use client';

import { useState } from 'react';

export function FadeToggle() {
  const [visible, setVisible] = useState(true);

  return (
    <>
      <button onClick={() => setVisible(v => !v)}>切り替え</button>
      <div
        className="transition-opacity duration-300"
        style={{ opacity: visible ? 1 : 0 }}
      >
        コンテンツ
      </div>
    </>
  );
}
```


## ページ遷移アニメーション

```tsx
'use client';

import { usePathname } from 'next/navigation';
import { useEffect, useRef, useState } from 'react';

export function PageTransition({ children }: { children: React.ReactNode }) {
  const pathname = usePathname();
  const [visible, setVisible] = useState(true);
  const isFirstRender = useRef(true);

  useEffect(() => {
    // 初回レンダリング時はスキップ
    if (isFirstRender.current) {
      isFirstRender.current = false;
      return;
    }
    // ページ変更時にいったん非表示 → すぐ再表示
    setVisible(false);
    const t = setTimeout(() => setVisible(true), 20);
    return () => clearTimeout(t);
  }, [pathname]);

  return (
    <div
      className="transition-opacity duration-300"
      style={{ opacity: visible ? 1 : 0 }}
    >
      {children}
    </div>
  );
}
```

`useRef` で初回レンダリングをスキップしている点がポイントです。これがないと、ページを開いた瞬間にフェードインアニメーションが走ってしまいます。

# 4. IntersectionObserver でスクロール連動アニメーション

スクロールして画面内に入ったタイミングで要素をアニメーション表示する実装です。

## ScrollReveal コンポーネント

```css
/* globals.css */
.scroll-reveal {
  opacity: 0;
  transform: translateY(24px);
  transition: opacity 0.5s ease-out, transform 0.5s ease-out;
  will-change: opacity, transform;
}

.scroll-reveal--visible {
  opacity: 1;
  transform: translateY(0);
}
```

```tsx
'use client';

import { useEffect, useRef } from 'react';

interface ScrollRevealProps {
  children: React.ReactNode;
  delay?: number;
}

export function ScrollReveal({ children, delay = 0 }: ScrollRevealProps) {
  const ref = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const el = ref.current;
    if (!el) return;

    const observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          el.style.transitionDelay = `${delay}ms`;
          el.classList.add('scroll-reveal--visible');
          observer.unobserve(el); // 一度表示したら監視解除
        }
      },
      { threshold: 0.1 }
    );

    observer.observe(el);
    return () => observer.disconnect();
  }, [delay]);

  return (
    <div ref={ref} className="scroll-reveal">
      {children}
    </div>
  );
}
```

## 使い方：記事カードを順番に表示

```tsx
{articles.map((article, index) => (
  <ScrollReveal key={article.id} delay={index * 60}>
    <ArticleCard article={article} />
  </ScrollReveal>
))}
```

`delay={index * 60}` で各カードが 60ms ずつずれて表示され、自然な「流れ込む」演出になります。

## スクロール連動 TOC ハイライト

目次（Table of Contents）で現在読んでいる見出しをハイライトする例です。

```tsx
'use client';

import { useState, useEffect } from 'react';

interface HeadingItem {
  id: string;
  text: string;
  level: 1 | 2 | 3;
}

export function TableOfContents({ headings }: { headings: HeadingItem[] }) {
  const [activeId, setActiveId] = useState('');

  useEffect(() => {
    const observer = new IntersectionObserver(
      (entries) => {
        entries.forEach((entry) => {
          if (entry.isIntersecting) {
            setActiveId(entry.target.id);
          }
        });
      },
      // 上80px・下70%の範囲に入ったら発火
      { rootMargin: '-80px 0% -70% 0%' }
    );

    headings.forEach(({ id }) => {
      const el = document.getElementById(id);
      if (el) observer.observe(el);
    });

    return () => observer.disconnect();
  }, [headings]);

  return (
    <nav>
      {headings.map(({ id, text, level }) => (
        <a
          key={id}
          href={`#${id}`}
          style={{
            paddingLeft: level === 3 ? '2rem' : level === 2 ? '0.75rem' : '0.25rem',
            fontSize: level === 3 ? '0.75rem' : '0.875rem',
          }}
          className={activeId === id ? 'text-foreground font-medium' : 'text-muted'}
        >
          {text}
        </a>
      ))}
    </nav>
  );
}
```

`rootMargin: '-80px 0% -70% 0%'` の意味：
- 上から 80px（固定ヘッダーの高さ分）を除外
- 画面下部 70% を除外 → 画面上部 30% のエリアに入った見出しをアクティブと判定

# まとめ：用途別の使い分け

| 用途 | 手法 | 特徴 |
|---|---|---|
| ホバー・フォーカス | Tailwind utilities | クラスだけで完結、最も手軽 |
| ページロード時のフェードイン | CSS `@keyframes` | `animation-delay` でずらせる |
| 無限ループ（浮遊・グラデーション） | CSS `@keyframes` | `infinite` で繰り返し |
| 状態変化（表示/非表示） | `useState` + CSS | JavaScript でタイミング制御 |
| スクロール連動 | IntersectionObserver | 一度だけ / 繰り返し 両対応 |

## はじめに

これまでテーブルデータでは分類を扱うことが多く、回帰はほとんど扱ったことがありませんでした。
そこで、回帰の評価指標と、学習で使う損失関数、目的変数の変換について整理しました。

整理してみると、「どの評価指標を使うか」と「どの損失関数で学習するか」「目的変数を対数変換するか」が互いに関係していて、
組み合わせによってモデルの最適な予測値そのものが変わることがわかりました。

この記事は、その関係を自分用に整理したメモです。後半には、LightGBM で簡単に試した結果も載せています。

## 回帰の主な評価指標

$y_i$ を実測値、$\hat{y}_i$ を予測値、$n$ をサンプル数とします。

| 指標 | 定義 | 単位 | 特徴 |
|---|---|---|---|
| MAE | $\frac{1}{n}\sum \lvert \hat{y}_i - y_i \rvert$ | 目的変数と同じ | 外れ値の影響を受けにくい |
| RMSE | $\sqrt{\frac{1}{n}\sum (\hat{y}_i - y_i)^2}$ | 目的変数と同じ | 大きな誤差を重く数える |
| R² | $1 - \frac{\sum (\hat{y}_i - y_i)^2}{\sum (y_i - \bar{y})^2}$ | なし | 平均値で予測した場合と比べた改善の割合 |
| MAPE | $\frac{1}{n}\sum \frac{\lvert \hat{y}_i - y_i \rvert}{\lvert y_i \rvert}$ | % | 誤差を実測値に対する比率で測る |
| MdAPE | $\mathrm{median}\left(\frac{\lvert \hat{y}_i - y_i \rvert}{\lvert y_i \rvert}\right)$ | % | MAPE の中央値版。大外れに左右されない |
| RMSLE | $\sqrt{\frac{1}{n}\sum (\log(1+\hat{y}_i) - \log(1+y_i))^2}$ | なし | 対数での誤差。比率の誤差に近い |
| PPE10 | $\frac{1}{n}\sum \mathbb{1}\left[\frac{\lvert \hat{y}_i - y_i \rvert}{\lvert y_i \rvert} \le 0.1\right]$ | % | 誤差が ±10% 以内に収まった割合 |

回帰の評価指標は、金額などの差で測る指標（MAE・RMSE）、実測値に対する比率で測る指標（MAPE・MdAPE・PPE10）、対数空間での誤差を測る指標（RMSLE）の3つに分けられます。
目的変数の値の幅が広い場合（桁が何段も異なる売上や金額など）、差で測る指標は値の大きいサンプルの誤差に支配されるため、比率や対数空間で測る指標が使われます。

比率で測る指標（MAPE・MdAPE・PPE10）には次の注意点があります。

- 実測値が 0 に近いと発散する（売上 0 の日がある需要予測などには向かない）
- MAPE・MdAPE は過小予測と過大予測で扱いが非対称になる（過小予測の誤差率は最大 100% だが、過大予測には上限がない）
- MdAPE は中央値なので、残り半分の予測がどれだけ悪くても値に出ない。PPE10 や、誤差率の上位の分位点と並べて使う

RMSLE は $\log(1+y)$ を使うため、実測値が 0 でも発散しません。$y$ と $\hat y$ が十分大きい範囲では比率誤差に近づきますが（$\log(1+\hat y) - \log(1+y) \approx \log(\hat y/y)$）、厳密には対数空間での誤差を測る指標です。

## 損失関数と「最適な予測値」

回帰モデルは、学習時の損失関数を小さくするように予測値を決めます。
同じ特徴量を持つサンプルの $y$ にばらつきがあるとき、損失関数によって「最適な予測値」が変わります。

| 損失関数 | 最適な予測値 |
|---|---|
| 二乗誤差（L2） $(\hat{y} - y)^2$ | $y$ の平均 |
| 絶対誤差（L1） $\lvert \hat{y} - y \rvert$ | $y$ の中央値 |
| 分位点損失（pinball loss、$\alpha$） | $y$ の $\alpha$ 分位点 |

つまり、L2 で学習したモデルの最適な予測値は平均、L1 で学習したモデルの最適な予測値は中央値です。
$y$ の分布が左右対称なら平均と中央値はほぼ同じですが、右に裾が長い分布（価格・売上・待ち時間など）では平均の方が大きくなり、両者の差が無視できなくなります。

このことから、評価指標に対応する損失関数で学習するのが基本になります。

- RMSE で評価するなら L2（最適な予測値は平均）
- MAE で評価するなら L1（最適な予測値は中央値）

## 目的変数の対数変換

目的変数の分布が右に裾が長い場合は、$\log y$ を予測するように学習し、予測値を $\exp$ で戻すことがよくあります。
このとき、損失関数との組み合わせで「最適な予測値」が変わります。

| 学習の仕方 | 対数空間での最適な予測値 | $\exp$ で戻した値 |
|---|---|---|
| $\log y$ を L2 で学習 | $\log y$ の平均 | $y$ の幾何平均（平均より小さい） |
| $\log y$ を L1 で学習 | $\log y$ の中央値 | $y$ の中央値（中央値は単調変換で変わらない） |

ポイントは次の 2 つです。

- $\log y$ を L2 で学習して $\exp$ で戻すと、予測は $y$ の平均より系統的に小さくなる。
  $\log y$ の平均を $\exp$ で戻した値は幾何平均で、算術平均以下になる（イェンセンの不等式）。
  RMSE や MAE で評価する場合や、合計値（売上の合計など）を合わせたい場合は、このずれが問題になる
- 平均を予測したい場合は補正が必要になる。$\log y$ の残差が正規分布に従うと仮定できるなら $\exp(\hat{\mu} + \sigma^2/2)$、
  分布を仮定しない場合は残差の $\exp$ の平均を掛ける方法（smearing 推定）がある

また、$\log y$ を L2 で学習することは、RMSLE を直接小さくすることにほぼ相当します（RMSLE は $\log(1+y)$ の RMSE）。

## 比率で測る指標と学習の対応

| 評価指標 | 対応する学習の仕方 | 補足 |
|---|---|---|
| RMSLE | $\log(1+y)$ を L2 で学習 | ほぼそのまま対応する |
| MdAPE | $\log y$ を L1 で学習 | $\lvert \log \hat{y} - \log y \rvert$ は、誤差が小さい範囲で誤差率 $\lvert \hat{y} - y \rvert / y$ にほぼ等しい |
| MAPE | 重み $1/y$ を付けて L1 で学習 | 最適な予測値は $1/y$ で重み付けした中央値で、中央値より小さくなる（後の実験では、この学習の仕方は最良にならなかった） |

MAPE の最適な予測値が小さめになるのは、値の小さいサンプルほど誤差率が大きく数えられるためです。
「MAPE を小さくする」ことと「典型的な値を予測する」ことは一致しない点に注意が必要です。

## まとめの対応表

| 目的 | 学習の仕方 | 評価指標 |
|---|---|---|
| 平均（合計を合わせたい） | L2 | RMSE |
| 中央値（典型的な値） | L1 | MAE |
| 比率で見た典型的な値 | $\log y$ を L1 | MdAPE、PPE10 |
| 比率で見た全体の誤差 | $\log y$ を L2 | RMSLE |
| 予測の幅 | 分位点損失 | 区間の被覆率と幅 |

## 実際に確かめる

California Housing（カリフォルニアの地区ごとの住宅価格の中央値）で、LightGBM の学習の仕方を変え、各評価指標を比べました。

- データ: 20,640 行・8 特徴。目的変数は住宅価格の中央値（単位は 10 万ドル。5.0 で打ち切られている）
- 学習の仕方: 生の値を L2 / 生の値を L1 / 生の値を重み $1/y$ 付きの L1 / $\log y$ を L2 / $\log y$ を L2 + smearing 補正 / $\log y$ を L1
- 検証: 5-fold CV の平均。LightGBM のハイパーパラメータは全条件で共通（調整なし）
- 予測平均比: 予測値の平均 ÷ 実測値の平均。1 より小さければ、全体として小さめに予測している

予想は、各指標でその指標に対応する学習の仕方が最も良くなること、$\log y$ を L2 で学習すると予測の平均が実測値の平均より小さくなることです。

| 学習の仕方 | RMSE | MAE | MAPE | MdAPE | RMSLE | PPE10 | 予測平均比 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 生の値 + L2 | 0.4393 | 0.2879 | 0.1614 | 0.1081 | 0.1327 | 0.470 | 1.000 |
| 生の値 + L1 | 0.4590 | 0.2865 | 0.1511 | 0.1012 | 0.1343 | 0.495 | 0.973 |
| 生の値 + L1（重み $1/y$） | 0.5215 | 0.3176 | 0.1518 | 0.1064 | 0.1478 | 0.476 | 0.928 |
| $\log y$ + L2 | 0.4527 | 0.2875 | 0.1497 | 0.1034 | 0.1317 | 0.487 | 0.978 |
| $\log y$ + L2 + smearing | 0.4508 | 0.2888 | 0.1522 | 0.1056 | 0.1316 | 0.478 | 0.989 |
| $\log y$ + L1 | 0.4611 | 0.2862 | 0.1489 | 0.0999 | 0.1345 | 0.500 | 0.969 |

（RMSE・MAE の単位は 10 万ドル。MAPE・MdAPE・PPE10 は比率）

### 予想どおりだった点

- RMSE は生の値 + L2 が最も良く、予測平均比もほぼ 1.000 だった（最適な予測値は平均）
- RMSLE は $\log y$ + L2 系の2条件が最も良く、smearing 補正ありの方がわずかに良かった（0.1316）
- MdAPE と PPE10 は $\log y$ + L1 が最も良かった
- $\log y$ + L2 は、$\exp$ で戻した予測の平均が実測値の平均より約 2% 小さかった（0.978）
- L1 で学習した条件は、最適な予測値が中央値のため、予測平均比が 0.97 前後と小さめになった

### 予想と違った点

- 重み $1/y$ 付きの L1 は、MAPE で最も良くならなかった。理屈の上では MAPE を直接小さくする学習の仕方だが、$\log y$ + L1 の方が良く、他の指標も大きく悪化した。
  値の小さい地区に重みが集中して学習が不安定になった可能性や、GBDT での L1 の最適化が近似であることが考えられるが、原因は確かめていない
- smearing 補正では、偏りが半分ほどしか戻らなかった（0.978 → 0.989）。学習データの残差から補正係数を計算しているため、LightGBM が学習データに過学習していると、残差が実際より小さく評価され、補正が不十分になる可能性がある。
  残差の分布が特徴量によって異なる場合、一律の補正係数では十分に対応できないことも考えられる。改善するなら学習データ内の OOF（Out-of-Fold）予測から残差を計算する方法があるが、今回は試していない（検証データの残差を使うと、同じデータで評価することになりリークになるため避ける）
- MAE は条件による差がごく小さく（0.2862〜0.2879）、fold によるばらつきの範囲の可能性がある

理屈どおりの対応関係はおおむね確認できましたが、「指標を直接小さくする重み付け」がそのまま最良にはなっていないです（ハイパーパラメータを全条件で共通にしているなど、今回の実験には不適切な箇所が含まれている可能性がありますが）。

## 分野ごとの定番の指標

調べた範囲では、分野によって標準的に使われる指標が異なります。

- 機械学習の教材・Kaggle: RMSE、MAE、R²、RMSLE
- 不動産の自動査定など（AVM: Automated Valuation Model）: 誤差率の中央値（MdAPE）と、±10% 以内に収まった割合（PPE10）の組み合わせ
- 需要予測・時系列予測: MAPE のほか、誤差の合計を実測値の合計で割る WAPE や、単純な予測（前の期の値など）と比べた誤差の比である MASE

## まとめ

- 損失関数によって、モデルの最適な予測値（平均・中央値・分位点）が変わる
- 目的変数を対数変換して L2 で学習すると、$\exp$ で戻した予測は平均より小さくなる
- 評価指標を決めたら、それに対応する学習の仕方を選ぶ（ただし、指標を直接小さくする重み付けが実際に最良になるとは限らないので、検証で確かめる）
